# 项目上下文

本文档记录项目决策、硬件细节和开发状态，供两台电脑（Windows 11 / macOS）通过 git 同步。

## 项目方向

- 删除循迹和避障功能，小车**只保留蓝牙遥控**功能
- 用户使用 iPhone，需要 BLE 4.0 模块
- 第一阶段用 LightBlue（iOS）调试验证
- 第二阶段自行开发 iOS App

## 蓝牙模块选型

| 项目 | 值 |
|------|----|
| 模块 | **HM-10**（已确定） |
| 核心芯片 | TI CC2541 |
| 蓝牙版本 | BLE 4.0 |
| 工作电压 | 3.3V |
| 通信方式 | UART 透传，MCU 侧无需关心蓝牙协议栈 |
| iOS 兼容 | 支持（BLE，非 SPP） |
| 尺寸 | 46 × 17 × 5 mm |
| 重量 | 3.2 g |

HC-06/HC-08 为经典蓝牙 SPP 协议，iOS 不支持，不可用。

### 出厂默认参数

| 参数 | 默认值 |
|------|--------|
| 波特率 | 9600 8N1 |
| 角色 | 从机（ROLE0） |
| 设备名 | HMSoft |
| 密码 | 000000（6位） |

### AT 命令配置说明

- **配置前提**：必须使用 USB 转 TTL 有线连接，**不可在无线配对状态下配置**（配对后数据直接透传，AT 命令无效）
- 未配对时 LED 慢闪，此时可发 AT 命令
- AT 命令**只支持全大写**，不支持小写或混合写法
- 修改波特率后需断电重启才生效
- 测试工具：资料包内 `HMBLEComAssistant.rar`（PC 端收发助手）
- iOS/Android 参考源码：http://www.jnhuamao.cn/download.asp?ID=0

### 本项目配置（从机）

```
AT+BAUD0       // 9600，改后断电重启
AT+NAMEAC      // 设备名改为 AC（可自定义）
AT+PASS000000  // 密码 6 位
AT+TYPE1       // 认证类型
AT+ROLE0       // 从机模式
```

## 硬件接线

### 电压（已确认）

扩展板 P16 蓝牙接口 VCC = **+3.3V**（来自原理图），HM-10 直接接，无需电平转换。

### P16 → HM-10 接线

| P16 引脚 | 信号 | HM-10 引脚 |
|---------|------|-----------|
| 1 | VCC（+3.3V） | VCC |
| 3 | RXD（PA10，USART1 RX） | TXD |
| 4 | TXD（PA9，USART1 TX） | RXD |
| 5 | GND | GND |

HM-10 的 STATE 和 BRK 引脚悬空不接。

### 安装注意

- HM-10 天线朝外，远离 L298N 和电机，避免电磁干扰

## 通信协议

波特率：**9600**（代码改为 `uart_init(9600)`，HM-10 默认值）

### 方向控制

| 动作 | 按下 | 松开 |
|------|------|------|
| 前进 | `ONA` | `ONF` |
| 后退 | `ONB` | `ONF` |
| 左转 | `ONC` | `ONF` |
| 右转 | `OND` | `ONF` |
| 停止 | `ONE` | `ONF` |

### 速度控制（9档）

| 速度档 | 按下 | 松开 |
|--------|------|------|
| 1（最慢） | `ON1` | `ONa` |
| 2 | `ON2` | `ONb` |
| 3 | `ON3` | `ONc` |
| 4 | `ON4` | `ONd` |
| 5 | `ON5` | `ONe` |
| 6 | `ON6` | `ONf` |
| 7 | `ON7` | `ONg` |
| 8 | `ON8` | `ONh` |
| 9（最快） | `ON9` | `ONi` |

速度 1~9 映射到电机速度 20~100，指令 3 字节定长 ASCII。
协议来源：原 HC-06 配套 Android App（BlueToothC.apk），直接复用。

## 固件改动清单

1. `uart_init(115200)` → `uart_init(9600)`
2. 删除 `tracking.c/h`，从 Keil 工程移除
3. 删除 `obstacle_avoidance.c/h`，从 Keil 工程移除
4. 删除 `key_value` 状态机和 `Driving_mode()`
5. 运动函数去掉 `delay_ms(time)`，改为立即执行
6. 新增蓝牙指令解析（解析 `USART_RX_BUF`）
7. 新增断连超时检测（500ms 无数据自动停车）
